# Вектор-студия

Фото превращается в векторную схему из цветных фигур, а схему можно править прямо на телефоне: двигать фигуры, перекрашивать, менять форму по узлам и сохранять в SVG или PNG.

**Открыть приложение:** https://emikhaylova18-pixel.github.io/My_claude_app/

## Что умеет первая версия

- Векторизация фото прямо в браузере, без сервера: палитра из 2–16 цветов, три уровня детализации, чистка мелких пятнышек, плавные линии с сохранением острых углов.
- Редактор: выбор и перемещение фигур, правка узлов (потянуть, добавить касанием контура, убрать), цвет из палитры рисунка или свой, «выше/ниже», копия, удаление, отмена и повтор.
- Жесты: одним пальцем двигать холст, двумя — масштаб.
- Режим «только линии» — схема для раскраски.
- Сохранение в SVG (открывается в CorelDRAW, Illustrator, Inkscape, Figma) и PNG. Проект сам сохраняется в браузере.

## Как устроен CI/CD

Файл `.github/workflows/ci-cd.yml`:

1. **CI.** На каждое изменение GitHub запускает тесты (`npm test`): векторизация, геометрия контуров, история отмены и сборка SVG.
2. **CD.** Если тесты прошли и изменение попало в ветку `main`, папка `app/` публикуется на GitHub Pages. Через минуту-две новая версия открывается по ссылке выше.

Если тесты упали, публикации не будет: на сайте останется прошлая рабочая версия.

## Структура

```
app/                 приложение (то, что публикуется)
  index.html         разметка
  styles.css         оформление
  src/trace.js       векторизация: палитра, области, контуры
  src/geometry.js    геометрия: площадь, упрощение, пути SVG
  src/history.js     отмена и повтор
  src/svg.js         сборка SVG-файла
  src/main.js        интерфейс редактора и жесты
tests/               автотесты (node --test), без внешних зависимостей
```

Запустить тесты локально: `npm test` (нужен Node.js 20 или новее).
