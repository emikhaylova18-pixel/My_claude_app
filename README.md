# Студия: фото и вектор

Два редактора для телефона в одном приложении. На старте выбираешь, с чем работать:

- **Растр — фоторедактор**, аналог Photoshop под палец.
- **Вектор — вектор-студия**: фото превращается в схему из фигур, которую можно править по узлам.

**Открыть приложение:** https://emikhaylova18-pixel.github.io/My_claude_app/

## Фоторедактор (растр)

- **Свет:** экспозиция, контраст, светлые, тени, белые, чёрные. **Цвет:** теплота, оттенок, сочность, насыщенность. **Детали:** резкость, чёткость, виньетка, выцветание, зерно. Кнопка «Авто» подбирает свет и цвет по гистограмме.
- **Фильтры:** 11 стилей (Яркий, Тёплый вечер, Прохлада, Пастель, Кино, Винтаж, Мягкий, Драма, Ч/Б, Нуар, Сепия) с регулировкой силы. Фильтр ложится поверх своих ползунков, ничего не затирая.
- **Кадр:** обрезка с соотношениями 1:1, 4:5, 3:4, 9:16, 16:9, 3:2, поворот на 90°, отражение, выравнивание горизонта.
- **Кисть и ластик:** цвет, размер, мягкость, плотность. Ластик стирает только рисунок, фото не трогает.
- **Ретушь:** точечное восстановление, как «Восстанавливающая кисть»: коснись пятнышка — оно исчезнет.
- **Текст:** три шрифта, цвет, размер, обводка, тень; перетаскивается пальцем.
- **Слои:** фото, рисунок и каждая надпись — отдельные слои с видимостью и прозрачностью.
- Кнопка «До» (удерживать) показывает оригинал. Отмена и повтор любых правок.
- Сохранение в JPG или PNG в полном размере или уменьшенным; на телефоне — «Поделиться». Оригинал не портится, правки сами сохраняются в браузере.

## Вектор-студия

- Векторизация фото прямо в браузере: палитра из 2–16 цветов, три уровня детализации, чистка мелких пятнышек, плавные линии с сохранением острых углов.
- Редактор: выбор и перемещение фигур, правка узлов, цвет, «выше/ниже», копия, удаление, отмена и повтор.
- Режим «только линии» — схема для раскраски. Сохранение в SVG и PNG.

## Как устроен CI/CD

Файл `.github/workflows/ci-cd.yml`:

1. **CI.** На каждое изменение GitHub запускает автотесты (`npm test`): обработка фото, ретушь, геометрия кадра, фильтры, векторизация, история отмены, сборка SVG.
2. **CD.** Если тесты прошли и изменение попало в ветку `main`, папка `app/` публикуется на GitHub Pages. Через минуту-две новая версия открывается по ссылке выше.

Если тесты упали, публикации не будет: на сайте останется прошлая рабочая версия.

## Структура

```
app/                    приложение (то, что публикуется)
  index.html            стартовый экран: растр или вектор
  photo.html            фоторедактор
  vector.html           вектор-студия
  styles.css            оформление
  src/home.js           стартовый экран
  src/photo/adjust.js   свет, цвет, детали, «Авто», гистограмма
  src/photo/filters.js  фильтры
  src/photo/transform.js  поворот, отражение, наклон, обрезка
  src/photo/heal.js     точечное восстановление
  src/photo/store.js    автосохранение в браузере (IndexedDB)
  src/photo/editor.js   интерфейс фоторедактора и жесты
  src/trace.js          векторизация: палитра, области, контуры
  src/geometry.js       геометрия контуров, пути SVG
  src/history.js        отмена и повтор (общая для обоих редакторов)
  src/svg.js            сборка SVG-файла
  src/vector.js         интерфейс вектор-студии
tests/                  автотесты (node --test), без внешних зависимостей
```

Запустить тесты локально: `npm test` (нужен Node.js 20 или новее).
